# Python Intent Classification Chatbot 🤖

A machine-learning chatbot built using Python, NLTK, NumPy, and TensorFlow/Keras. The chatbot predicts the intent behind a user's message and returns a relevant predefined response from a JSON dataset.

The project includes both a **command-line interface (CLI)** and an interactive **Streamlit web interface**, allowing users to interact with the chatbot through a terminal or browser.

This project helped me explore Python, natural language preprocessing, bag-of-words, neural networks, model training, inference, and building a simple web interface for a machine-learning application.

## ✨ Features

- Text tokenization and normalization using NLTK.
- Vocabulary generation from training patterns.
- Bag-of-words feature extraction.
- Intent classification using a neural network.
- Model training and saving with TensorFlow/Keras.
- Loading a trained model for predictions.
- Random response selection based on the predicted intent.
- Command-line interface for terminal-based conversations.
- Interactive Streamlit web interface with chat-style messages.

## 🛠️ Technologies Used

- **Python** — Core programming language.
- **NLTK** — Text tokenization and lemmatization.
- **NumPy** — Numerical operations and feature representation.
- **TensorFlow / Keras** — Neural-network training and inference.
- **Streamlit** — Interactive web interface.
- **JSON** — Intent patterns and predefined responses.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Saksham-Sharma-webdev/Python-intent-classification-chatbot.git
cd Python-intent-classification-chatbot
```

### 2. Create a virtual environment

On Windows:

```powershell
python -m venv .venv
```

Activate it in PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```


### 3. Install dependencies

Upgrade pip and install the required libraries:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Ensure that `requirements.txt` includes Streamlit and the libraries required by your chatbot, including TensorFlow, NLTK, and NumPy.

### 4. Train the model

If the trained model is missing, or if you have modified the intent dataset, run:

```bash
python -m src.train
```

The training script trains the neural network and saves the trained model to the `models/` directory.

Run this command from the project root directory.

### 5. Run the chatbot using the command line

```bash
python -m src.chatbot
```

Enter a message when prompted. Type `quit` or `exit` to stop the chatbot.

### 6. Launch the Streamlit web interface

To interact with the chatbot through your browser, run:

```bash
python -m streamlit run app.py
```

Streamlit starts a local web server and typically opens the application in your default browser.

Visit the local URL displayed in the terminal, usually:

```text
http://localhost:8501
```

You can now send messages through the chat input, view responses, maintain conversation history during the session, and clear the conversation using the sidebar.


## 🧠 How It Works

1. **Intent Dataset:** `data/intents.json` contains intent tags, example patterns, and possible responses.
2. **Preprocessing:** Input text is tokenized, normalized, and lemmatized using NLTK.
3. **Vocabulary Creation:** A vocabulary is generated from the words in the training patterns.
4. **Bag-of-Words:** Each input message is converted into a numerical vector based on the vocabulary.
5. **Neural Network:** TensorFlow/Keras predicts the intent class from the input vector.
6. **Response Selection:** Python identifies the predicted intent in the JSON dataset and randomly selects one of its predefined responses.
7. **User Interface:** The chatbot can be accessed through the command line or a Streamlit web interface.

## ⚠️ Limitations

- This is an educational project and is not intended as a production-ready chatbot.
- A small training dataset can lead to overfitting.
- High training accuracy does not guarantee correct predictions on unseen messages.
- Bag-of-words does not effectively capture word order or semantic meaning.
- Responses are predefined rather than generated by a large language model.
