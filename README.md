
# Python Intent Classification Chatbot 🤖

A simple machine-learning chatbot built using Python, NLTK, NumPy, and TensorFlow/Keras. The chatbot predicts the intent behind a user's message and returns a relevant predefined response from a JSON dataset.

This project helped me learn Python, natural language preprocessing, bag-of-words, neural networks, model training, and inference.

## ✨ Features

- Text tokenization and normalization using NLTK.
- Vocabulary generation from training patterns.
- Bag-of-words feature extraction.
- Intent classification using a neural network.
- Model training and saving with TensorFlow/Keras.
- Loading a trained model for predictions.
- Random response selection based on the predicted intent.
- Basic handling of empty messages and unknown vocabulary words.

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Replace the URL with your own GitHub repository URL.

### 2. Create a virtual environment

On Windows:

```powershell
python -m venv .venv
```

Activate it in PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the chatbot

From the project root directory:

```bash
python src/chatbot.py
```

Enter a message when prompted. Type `quit` or `exit` to stop the chatbot.

### 5. Train the model

If the trained model is missing, or you have changed the intent dataset, run:

```bash
python src/train.py
```

The training script trains the neural network and saves the model to the `models/` directory.

After training, start the chatbot again:

```bash
python src/chatbot.py
```

## 🧠 How It Works

1. **Intent Dataset:** `data/intents.json` contains intent tags, example patterns, and possible responses.
2. **Preprocessing:** The input text is tokenized, converted to lowercase, stripped of punctuation-only tokens, and lemmatized.
3. **Vocabulary Creation:** A vocabulary is generated from the words in the training patterns.
4. **Bag-of-Words:** The input message is converted into a numerical vector based on the vocabulary.
5. **Neural Network:** TensorFlow/Keras predicts the intent class from the input vector.
6. **Response Selection:** Python finds the predicted intent in the JSON dataset and randomly selects one of its responses.

## ⚠️ Limitations

- This is an educational project and is not intended as a production-ready chatbot.
- A small training dataset can lead to overfitting.
- High training accuracy does not guarantee correct predictions on unseen messages.
- Bag-of-words does not capture word order or semantic meaning effectively.
- Responses are predefined rather than generated by a large language model.
- The chatbot does not currently implement document retrieval or a RAG pipeline.
